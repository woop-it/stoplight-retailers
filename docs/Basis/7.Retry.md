# Retry process (fail)

![Booking_and_order_concept_annexes.png](../../../assets/images/Process_flux_retry_for_order.jpg)

- The system must limit to a configured maximum number of 5 attempts of 3 retries par minute.
- The system replays these retries every 15 minutes
- If no ACK is received after the maximum number of retries, the callback is sent in a Dead Letter Queue.
- Recording (Logs) and monitoring in the event of a definitive failure to inform the retailer
